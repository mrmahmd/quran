# منصة المدرسة القرآنية

واجهة عربية لمدارس الأندلس الأهلية — المسار المصري، فرع الحمدانية.

تتيح المنصة مستقبلًا لمعلمي القرآن تسجيل الحفظ والمراجعة والحضور، وإعداد التقييمات الشهرية، مع تقارير موحّدة للإشراف والإدارة.

## النسخة الحالية

تتضمن النسخة الأولى الصفحة الرئيسية ونموذج تسجيل الدخول التجريبي للمعلم والمشرف والإدارة. ربط الحسابات وقاعدة البيانات سيكون في المرحلة التالية.

يُنشر محتوى مجلد `dist` تلقائيًا على GitHub Pages عند تحديث الفرع `main`.
