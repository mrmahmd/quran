# منصة المدرسة القرآنية

واجهة عربية لمدارس الأندلس الأهلية — المسار المصري، فرع الحمدانية.

تتيح المنصة لمعلمي القرآن إدخال نقاط التقييم الأسبوعي، واختيار فارس الأسبوع، وحفظ التكريم الفصلي، مع تقارير للإدارة.

## النسخة الحالية

تتضمن المرحلة الحالية ١٨ اسم مستخدم للمعلمين مرتبطًا بـ١٨ فصلًا في مشروع Supabase، بالإضافة إلى حساب إدارة عليا ببريده الإلكتروني. يتفعّل كل حساب برمز خاص من ٦ أرقام لمرة واحدة، ثم يختار صاحبه كلمة مرور من ٦ أحرف على الأقل. يُوقف التفعيل مؤقتًا بعد خمس محاولات خاطئة خلال ١٥ دقيقة. اسم `quran05` محجوز ولا يُستخدم بعد استبعاد المعلم المكلف سابقًا بالفصل `4/B`.

شغّل ملف `supabase/teacher-onboarding.sql` عند إنشاء مشروع جديد، ثم جهّز قائمة المعلمين ورموز التفعيل في مكان خاص خارج المستودع. رموز المشروع الحالي محفوظة محليًا في `private/teacher-activation-cards.txt` ورمز الإدارة في `private/admin-activation-card.txt`، والمجلد مستثنى من Git. تُسلَّم بطاقة كل معلم له وحده ورمز الإدارة لصاحب البريد فقط. لا يوجد تسجيل مفتوح للحسابات؛ التفعيل يتم عبر وظيفتي Supabase في `supabase/functions`.

لوحة المعلم تضم نقاط الحفظ والمراجعة والتحسن الذاتي والالتزام، ونقطتي التميز الاختياريتين. يمكن حفظ مسودة ثم اعتماد الأسبوع؛ تعديله بعد الاعتماد يحتاج إعادة فتحه بواسطة الإدارة. تعرض لوحة الإدارة جميع الحلقات وتتيح تجهيز الفصول الدراسية وقوائم الطلاب. أُضيفت القوائم الواضحة من ملف المدرسة، وتُركت الأسماء المتعارضة للمراجعة. دورة التقييم الحالية ١٢ أسبوعًا من ٢٧ سبتمبر إلى ١٧ ديسمبر ٢٠٢٦، وترقيمها يبدأ بالأسبوع الخامس وينتهي بالسادس عشر.

ملف `supabase/dashboard.sql` ينشئ جداول التقييم وصلاحياتها، وقد طُبق على المشروع الحالي. يُشغّل مرة واحدة بعد تجهيز حسابات المعلمين والإدارة. جميع الجداول محمية بـRLS؛ الحفظ يتم عبر وظائف تتحقق من صاحب الحساب، وحدود النقاط، واكتمال الاعتماد، وتعارض التعديلات. ملف `supabase/tests/dashboard-security.sql` اختبار صلاحيات داخل معاملة تنتهي بالتراجع دون ترك بيانات تجريبية. اختبارات حساب النقاط: `node --test tests/evaluation-model.test.mjs`.

يُنشر محتوى مجلد `dist` تلقائيًا على GitHub Pages عند تحديث الفرع `main`.

صلاحية مشرف الطلاب منفصلة عن الإدارة: إضافة وتعديل ونقل وأرشفة واستعادة الطلاب دون تعديل تقييمات الحلقات الأخرى. ملف `supabase/roster-management.sql` يجهز هذه الصلاحية والحقول اللازمة؛ منحها للحساب المحدد يتم خارج ملفات المستودع. النقل مع وجود تقييمات يؤرشف السجل السابق ويبدأ سجلًا في الحلقة الجديدة حفاظًا على التاريخ. قوائم الطلاب وملفات الاستيراد والمراجعة داخل `private/` ولا تُنشر على GitHub.
