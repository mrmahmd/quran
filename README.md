# منصة المدرسة القرآنية

واجهة عربية لمدارس الأندلس الأهلية — المسار المصري، فرع الحمدانية.

تتيح المنصة مستقبلًا لمعلمي القرآن تسجيل الحفظ والمراجعة والحضور، وإعداد التقييمات الشهرية، مع تقارير موحّدة للإشراف والإدارة.

## النسخة الحالية

تتضمن المرحلة الحالية ١٨ اسم مستخدم للمعلمين مرتبطًا بـ١٨ فصلًا في مشروع Supabase، وصفحة لتفعيل الحساب برمز خاص لمرة واحدة واختيار كلمة المرور، ثم تسجيل الدخول وعرض اسم المعلم وفصله. اسم `quran05` محجوز ولا يُستخدم بعد استبعاد المعلم المكلف سابقًا بالفصل `4/B`.

شغّل ملف `supabase/teacher-onboarding.sql` عند إنشاء مشروع جديد، ثم جهّز قائمة المعلمين ورموز التفعيل في مكان خاص خارج المستودع. رموز المشروع الحالي محفوظة محليًا في `private/teacher-activation-cards.txt`، والمجلد مستثنى من Git. تُسلَّم بطاقة كل معلم له وحده. لا يوجد تسجيل مفتوح للحسابات؛ التفعيل يتم عبر وظيفة `supabase/functions/activate-teacher/index.ts` المنشورة في Supabase.

لوحات متابعة الحفظ والطلاب وتقارير الإدارة مؤجلة للمرحلة التالية.

يُنشر محتوى مجلد `dist` تلقائيًا على GitHub Pages عند تحديث الفرع `main`.
